LinkedIn Profiles

Enter a company website (e.g. stripe.com) or a LinkedIn company URL. We resolve the company, read its name off LinkedIn, then Google site:linkedin.com/in/ "Company Name" via Bright Data to surface employee profiles — with the total cost.

API — run this search programmatically

One JSON endpoint. If a run isn't cached it starts in the background and returns 202 {status:"running"} — poll the same URL until it returns 200 with the result (~1–2 min). It's cached after, so repeat calls are instant & free.

GET https://dataengine.hyndlandpartners.com/linkedin-profiles/api/report?input=<company>

Params

  • input — company website (e.g. stripe.com) or a LinkedIn company URL
  • refresh=1 — start a fresh run, ignoring any cached report
  • run=0 — cache-only: returns 404 if nothing's saved (never starts a run)

Auth — same basic-auth credentials as this site.

Poll it — Bash

BASE='https://dataengine.hyndlandpartners.com/linkedin-profiles/api/report?input=stripe.com'
while :; do
  code=$(curl -s -o out.json -w '%{http_code}' -u USER:PASS "$BASE")
  [ "$code" = 200 ] && break     # 202 = still running
  sleep 10
done
cat out.json

Poll it — Python

import time, requests

URL  = "https://dataengine.hyndlandpartners.com/linkedin-profiles/api/report"
AUTH = ("USER", "PASS")

while True:
    r = requests.get(URL, params={"input": "stripe.com"}, auth=AUTH)
    if r.status_code == 200:
        data = r.json(); break        # done
    time.sleep(10)                    # 202 = still running

print(data["count"], "people ·", "$" + str(data["cost"]["usd"]))
for p in data["people"]:
    print(p["rank"], p["name"], "-", p["job_title"], "@", p["current_company"])

Poll it — PHP

<?php
$url  = "https://dataengine.hyndlandpartners.com/linkedin-profiles/api/report?input=stripe.com";
$auth = "USER:PASS";

while (true) {
    $ch = curl_init($url);
    curl_setopt_array($ch, [CURLOPT_RETURNTRANSFER => true, CURLOPT_USERPWD => $auth]);
    $body = curl_exec($ch);
    $code = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);
    if ($code === 200) { $data = json_decode($body, true); break; }  // done
    sleep(10);                                                        // 202 = still running
}

echo $data["count"] . " people\n";
foreach ($data["people"] as $p) {
    echo "{$p['rank']} {$p['name']} - {$p['job_title']} @ {$p['current_company']}\n";
}

Returns — company_name, employees, searches, cost{usd,brightdata_calls}, count, profiles_found, people[]. Each person: rank, name, first_name, last_name, linkedin_url, job_title, current_company, current_city, matched_searches. people = the up-to-12 confirmed still at the company.
