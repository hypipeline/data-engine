Model Comparison · Stage 1 — Name Extraction

The first LLM pass. This stage is not about finding the final entity — it's about extracting good, real data (entity names, key people, addresses) for Stage 2 to search on. So each case is graded on how much of the good data it recovers. The reference set is the ideal record, built automatically by pooling what every model proposes (plus the live production model), keeping only items that actually appear in the website text (regex-grounded — hallucinations and training-only facts like a known parent are dropped), and de-duplicating. Each candidate model is then scored on recall of that consensus set across the three dimensions. Contrast with Stage 2 — Analysis, which scores the final recommended entity.
